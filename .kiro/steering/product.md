# Product: NightOwl BBS
Resurrect the dial-up-era Bulletin Board System as a modern web community board.
- Look & feel: 80x25 ANSI terminal in the browser (CP437-style box drawing, 16-color palette, blinking cursor, modem "handshake" connect screen).
- Interaction: keyboard-first menus ([M]essage bases, [F]iles, [W]ho's online, [G]oodbye), like Renegade/WWIV boards.
- Modern twist: an LLM "SysOp" agent that greets callers, moderates posts, summarizes threads, and answers questions in-character as a 1994 sysop.
- Must work with no API key (SysOp falls back to a rule-based persona).
Audience: retro-computing fans and small communities who want a cozy, low-noise forum.
